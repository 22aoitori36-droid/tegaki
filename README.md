# 手書きノート（iPad 用 PWA）

Apple Pencil で書ける手書きノート。ビルド不要の静的ファイル（HTML/CSS/ES モジュール）。

## 機能
- ノート（表紙色・用紙）を複数作成、縦スクロールでページを追加
- 分野ごとのフォルダ（一覧上部のタブ。選択中のタブをもう一度押すと名前変更・まとめてPDF・削除）
- 手ぶれ補正（オフ／弱／中／強、既定は中。ゆっくりした揺れを強くならし、速い線は遅らせない）
- ペン（筆圧対応）・蛍光ペン・消しゴム（線ごと）・なげなわ（選択して移動／複製／削除）
- 用紙：無地／罫線／方眼／ドット（ページごと）
- 取り消し・やり直し（ボタン、2本指タップ、⌘Z / ⇧⌘Z）
- 2本指でピンチズーム・スクロール。ペンで書いている間は手のひらでスクロールしない
- 「指で書く」切り替え（オフ時：ペンだけ書ける、指はスクロール）
- PDF 書き出し（A4・200dpi）：ノート単位（編集画面上部の書き出しボタン）／フォルダ単位でまとめて、ページの PNG 保存、全ノートの JSON バックアップ／復元
- オフライン動作（Service Worker）、データは端末の IndexedDB に保存

## ファイル
- `index.html`, `style.css`
- `js/app.js` 一覧・エディタ・描画・入力処理
- `js/db.js` IndexedDB（notebooks / pages / folders、DB バージョン 2）
- `js/pdf.js` JPEG を貼った最小 PDF の生成
- `sw.js` オフライン用キャッシュ（**更新時は VERSION を上げる**）
- `make_icons.py` アイコン PNG 生成（依存なし）

## データ形式
ページ座標は幅 1000 × 高さ 1414（A4 比）。線は `{t:'pen'|'hl', c:色, w:太さ, p:[x,y,筆圧,...]}`。

## 公開
GitHub Pages などに置き、iPad の Safari で開いて「共有 → ホーム画面に追加」。
